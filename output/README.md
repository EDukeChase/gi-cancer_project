# /output/ Directory

This folder stores all generated outputs from the analysis, such as figures, tables, and rendered documents.

**Note:** The contents of this folder are intentionally ignored by git (as specified in the project's `.gitignore` file).

## Contents

* `figures/`: Contains all exported plots and graphs. Per project requirements, this includes high-resolution `.svg` files for publication and `.png` files for quick viewing.
* `tables/`: For any exported summary tables (e.g., as `.csv` or `.html`).
