# /docs/ Directory

This folder contains supplementary documentation, project notes, and archival materials that provide context but are not part of the reproducible analysis. The contents of this folder are not backed up to GitHub.

**Note:** The contents of this folder are intentionally ignored by git (as specified in the project's `.gitignore` file).

## Contents

* `Brief concept for project discussion.docx`: A Word document outlining the original project scope, initial ideas, and the state of files prior to this analysis.
* `original_contents/`: A folder containing all original/unmodified documents from shared folder
