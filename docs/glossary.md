# Medical Glossary

**Note on Longitudinal Data:**
Variables ending in a suffix `_#` (e.g., `_0`, `_1`) represent measurements taken at specific time points:
* `_0`: Baseline (Pre-treatment)
* `_1` through `_12`: Chemotherapy Cycles 1-12
